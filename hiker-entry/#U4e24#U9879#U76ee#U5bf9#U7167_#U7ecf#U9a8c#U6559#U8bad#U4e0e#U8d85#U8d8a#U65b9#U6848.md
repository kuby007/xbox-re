# 两项目接口支持度对照、经验教训与超越方案

> 阶段七 · 基于 `hikerView`（原版核心模块）与 `xingchen`（星辰播放器）逐文件实证
> 目的：回答「两个项目是否完全支持用户提供的那些接口」，并据此完善 `oktv-cat-hiker-entry`
> 所有结论均来自仓库源码与本地可跑实证，不用推测；证据文件见文末清单。

---

## 0. 结论先行

**「完全支持」的答案是：两个项目都没有完全支持，而且缺的不是同一类东西。**

| 项目 | 对「用户历次提供的接口」的覆盖 | 定性 |
|---|---|---|
| `hikerView` | 规则引擎侧 **100%**（它就是接口定义方：`JSEngine` 100 个 `@JSAnnotation` API + `CodeUtil`/`HikerRuleUtil` 的 `hiker://` 分发）；但 `fy_bridge_app` 只有 `help_web_bridge.json` 文档、**Java 实现不在开源范围**（README 明说「为避免被打包…只开放核心模块」）；v390 / wogg / oktv-cat 的桥形态、宿主集成、口令站点管理全部没有 | **权威但不完整、不可集成**（独立 App，2024-04 停更） |
| `xingchen` | 用 Rhino + 9211 行 `HkJsRuntime` + 60 个 `api/hk/` + 70 个 `ui/hk/` 类**逐行照抄 8.83**，语义等价覆盖高；但交付清单里明确列着多条「本地已修、未编、待真机验」漏项，且不含 WebView 的 4 套同步桥形态、不做能力分级、不接宿主 fm SDK | **重但脆弱**：靠逐行仿写维持兼容，规则一变就要跟着重做 |
| 我们（阶段六） | 独立 WebView + 4 形态同步桥 + 形态探测/语义归一/显式降级 + 宿主播放/口令/站点注入；但官方 134 个真实使用 API **只覆盖 36 个** | 轻、可集成，但接口面太窄 |
| 我们（阶段七） | **134/134 符号可见**（93 真实现 / 25 桥转发 / 12 保留 / 4 显式降级）+ 完整 `hiker://` 分发 + 新鲜作用域 + 播放交接双认 | 用官方契约做尺子、吸收真机教训、保留多变适配 |

**关键发现：用户历次给的「接口」其实横跨两套体系**——
① **Rhino 规则引擎 API**（`fetch`/`pdfh`/`setResult`/`MY_URL`…，`hikerView` 的 `JSEngine` 用 Java 同步实现）；
② **WebView 网页桥**（`fy_bridge_app.getInternalJs()` / `window.fetch` 重写，`home.js` 用它）；
再加上 ③ 宿主侧桥形态（v390 `FM_SHELL`/`FM_JSREQ`、wogg 异步 `window.fm`、oktv-cat `fongmiBridge`）。
前两个项目各占一侧，`hikerView` 甚至在开源部分里连 ② 的实现都删了。这正是"完全支持"做不到的根因，也是我们的机会。

**「超越」的确切含义不是比谁重**（`hikerView` 1532 个 Java、`xingchen` 1903 个 Java），而是：
> 用官方契约当尺子 + 吸收两个项目的真机教训 + 保留多变适配与宿主集成 + 结构性规避它们的缺陷。

## 4. 经验（可借鉴，已吸收）

| 经验 | 证据 | 吸收方式 |
|---|---|---|
| **官方 API 是有清单的，不该靠猜** | `help_js.json` 82 章 / `JSEngine` 100 `@JSAnnotation` / `help_web_bridge.json` 27 方法 | 生成 `hiker_official_contract.json`，兼容层按契约表逐项补齐，覆盖率可量化 |
| **引擎必须进程单例、变量按规则隔离** | `HK_REDO_BLUEPRINT.md:41`「A1 引擎必须进程单例…变量按 规则名@key 隔离、preRule 每规则一次」；`HkEngineManager.ruleKey()` | `HikerApiSurface` 模块级共享状态 + `key(k, r)` 规则级隔离 + `setRuleKey()` |
| **`hiker://` 必须走 scheme 分发，不能直连网络** | `CodeUtil.java:47-67`、`HikerRuleUtil.java:88-130`、`HK_REDO_BLUEPRINT.md:184-194` | 新建 `hiker_scheme.js`，逐类还原 8.83 分发链 |
| **错误码是契约的一部分** | `HikerRuleUtil` 异步版：格式不对→404「格式有误」、异常→500「获取数据失败」；`CodeUtil` 文件不存在→404 | `dispatch()` 返回 `{ok,status,body,error}` 并上报，不静默给空串 |
| **`fy_bridge_app` 有 27 个方法，不只有 `fetch`** | `help_web_bridge.json`、`home.js:951/971/1298` 的 `x5WebView://javascript:` 注入 | `hiker_bridge_adapter.js` 从 8 个方法扩到 28 个 |
| **播放/详情/搜索是三条独立回调链** | `JsEngineBridge.java` 三个 `parseCallBack`，非主线程直接同步执行、主线程 `new Thread` | 印证「同步字符串」硬约束，我们的独立同步桥方向正确 |
| **`$` 工具是 `Hikerurl.js` 定义的** | `hikerView/Hikerurl.js` 57 行（`rule`/`lazyRule`/`x5Rule`/`param`），`xingchen` 扩到 520 行（加 `$require` 模块加载器） | 保留 shim 的 jQuery 风格化包装，不重复实现 |

## 5. 教训（缺陷与妥协，已规避）

| # | 真机事故 / 缺陷 | 根因 | 我们的规避 |
|---|---|---|---|
| 1 | **1.2.8 所有规则打不开**：`Expected URL scheme 'http' or 'https' but was 'hiker'` | 适配时把 `CodeUtil` 分发换成直连 OkHttp，`hiker://empty##fypage` 必死；`HkCodeUtil` 早已移植却零调用 | F 组 15 个用例全过；`fetch('hiker://empty')` 命中分发，绝不落到网络桥 |
| 2 | **`getUaObject 未定义`**（点播放/分类钮） | 发布包开 R8 混淆，`HkJsRuntime` 靠**反射按方法名**生成 JS 包装函数被改名；新鲜作用域求值时 `JSON.parse(getUaObject())` 直接挂 | ① 我们的 Java 桥是**显式 `@JavascriptInterface`**，不经反射，结构性免疫；② `installFresh()` 在新作用域装全量 API。G 组先复现事故（`TypeError: getUaObject is not a function`），再 3/3 产出 `setResult` |
| 3 | **`getJsPlugin 未定义`** | 新鲜作用域只补了 `MY_*`，没补预置函数 | 同上，134 个 API 全量注入 |
| 4 | **加密封面全灭** | `@js=` 求值要用的 `HkImage.setCurrentRuntime` 新模块从未登记 | 诚实列入「宿主依赖」，不伪装修好 |
| 5 | **多线路/headers 全丢** | `PlayData.headers` 是对象数组 `[{Referer:…}]`，宿主只认 `"K@V"`；`names`（完整版/预览）压成单条「默认」；标题取规则名 | `AS.normalizePlayData()` 双认 + `flags` 保留多线路（J 组 3/3） |
| 6 | **`clearTag` 按 `#` 截断** | 砍掉 `hiker://empty#http://…` 的真实地址 | `hiker_scheme.js` 只丢纯标记段，保留含 `://`/`@rule=`/`js:` 的段（F 组验证） |
| 7 | **靠逐行照抄维持兼容** | 57 `col_type`、34 Holder、167 图片映射、6 个 `notify*` 方法逐个对 smali；「验完再删死代码」 | 我们不复刻 UI，改用**契约表 + 能力分级 + 显式降级**，规则变了改契约不改 1900 个 Java |
| 8 | **「本地已修、未编、待真机验」堆积** | `DELIVERY_NEXT.md` 里 1.2.9/1.3.0/1.3.1 多批并列，静态自检通过不等于真机可用 | 我们把「真机回归」列为 P0 未闭合项，并明确离线 stub 口径的覆盖率不是真机数字 |
| 9 | **两个项目都不做能力分级** | 缺失 API 直接抛 undefined，或静默返回空 | 四档 `full/bridge/delegate/degrade` + `lastError` 上报，杜绝假阳性 |

## 7. 仍未闭合（必须说清）
