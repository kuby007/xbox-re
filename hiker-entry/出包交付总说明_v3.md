## 六、仍不可兼容（诚实边界）

- 3 个内核依赖 API 明确降级：`fetchCodeByWebView` / `x5Rule` / `parseLazyRuleAsync`（返回空串并留痕，不伪装成功）。
- 4 个 `degrade` 档：代理服务 / DNS / 注册任务 / 取消任务。
- Rhino 专有语法规则、Python(Chaquopy) 规则、私有加密规则、`loadJavaClass` Java 字节码、
  X5 内核嗅探、原生 UI（57 `col_type` / 34 Holder）：仅识别并降级，不执行。
- **真机最小探针**（`addJavascriptInterface` + 一次同步 `req`）与全库真机回归未做——这是「能当海阔完整可用版」发布前的最后一项 P0。
- M3U8 是内容级改写 + 落盘，不是本地代理服务；`clearM3u8Ad` 为启发式；AES MD5-key 派只覆盖常见写法；QR 限 version 1~10 / ECC-M / 固定 mask 0。

## 七、如何判断现在这个包

- **能装上看效果 / 演示六段链路 + 纯 JS 规则**：现在就出，`assembleLeanbackDebug` 即可。
- **当「海阔完整可用版」发布**：建议先做真机最小探针 + 全库真机回归；凡规则用到 3 个内核依赖 API 或 4 个 degrade 档仍会落空串/降级（有留痕，不静默假成功）。
